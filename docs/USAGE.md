# 使用文档

本文档面向第一次运行 SentimentAnchor 的使用者，覆盖安装、配置、页面操作、交易流程、风控、回测和数据边界。

> **这不是投资建议，也不是已验证的实盘产品。**  
> Windows 适配器已完成 dry_run/查询联调；真实资金报单、撤单和成交回读仍需小额验证。  
> 完整免责声明见 [DISCLAIMER.md](../DISCLAIMER.md)。

## 1. 系统是什么

SentimentAnchor 是一个单操作者的 A 股研究与交易工作台：

```text
行情 → 情绪评分 → 锚点/主线 → 策略/回测 → 风控 → 券商队列 → 账本/复盘
```

包含：

- 情绪锚看板
- T+0 ETF 交易台
- T+1 股票量化
- 风控编排
- 1 分钟分时分析
- 日线回测
- 公司行为/公告
- 盘前候选
- 交易计划/复盘
- 自动备份/手机告警

不包含：

- 股票/ETF 模拟账户
- 多用户/RBAC
- Level-2 / 逐笔 / 融资融券
- 保证盈利的策略

## 2. 环境要求

```text
Node.js >= 20.10
pnpm >= 11
```

Windows 实盘还需要：

```text
Windows 10/11 交互式桌面
同花顺网上股票交易系统 5.0
部署仓库内 thsapi 适配器
```

## 3. 安装

```bash
git clone git@github.com:licc/SentimentAnchor.git
cd SentimentAnchor
pnpm install
cp .env.example .env
```

`.env` 是本机配置，**不要提交**。

## 5. 页面

### 5.1 情绪锚看板 `/`

回答：

```text
今天市场能不能做？
情绪处于什么阶段？
谁是空间锚/换手锚/容量核心？
主线是什么？
风险在哪里？
```

包含：

- 指数条
- 外围情绪：VIX、美股期货、黄金、CNH、韩国、日本
- 情绪温度/阶段/风险
- 9 个动态锚点
- AI 研判
- 辨识度双榜
- 周期规则/日历
- 自选/预警/数据源状态

### 5.2 交易台 `/jyt`

四个页签：

```text
主动交易
T+0 交易
量化交易（T+1）
风控
```

账户和持仓是 T+0/T+1 共用的；策略、额度、风控作用范围分开。

## 6. 首次配置

### 6.1 访问口令（可选）

`.env`：

```env
APP_TOKEN=一段足够长的随机字符串
```

设置后前端显示登录页。没有多用户/RBAC。

### 6.2 券商适配器

在 Windows 上启动仓库内的 `thsapi` 适配器，再在页面：

```text
交易台 → 系统设置 → 交易接口
```

填写：

```text
接口地址：http://127.0.0.1:8888
API Key：可留空
```

点“测试接口”。

注意：

- Key 为空时不会发送 `X-API-Key`。
- 要清除已保存 Key，勾选“清除已保存 Key”再保存。
- 页面配置保存在 `data/runtime-config.json`。
- 环境变量 `ETF_BROKER_URL` / `ETF_BROKER_KEY` 优先级更高。

没有适配器时：

```text
接口显示离线
不能下单
T+0/T+1 自动执行不能启动
```

这是正常行为，不是前端故障。

### 6.3 AI（可选）

```text
工具 → AI 设置
```

可配置 OpenAI 兼容接口：

```text
Base URL
API Key
Model
```

不配置时使用本地量化规则推理；配置后才有“LLM 深度研判”。

AI 只生成文本/参数草稿，不直接下单。

### 6.4 手机告警（可选）

```text
系统设置 → 手机告警
```

支持：

```text
Server酱
PushPlus
Webhook
```

Webhook 会拒绝内网/回环地址。

### 6.5 自动备份

```text
系统设置 → 自动备份
```

备份 `data/` 下的 JSON/SQLite 到 `data/backups/`；默认保留 14 份。

## 7. 每日流程

### 7.1 盘前

```text
1. 启动行情服务
2. 打开 /jyt
3. 查看顶部盘前候选
4. 检查候选的 100 股成本/额度
5. 打开个股详情看公告风险
6. 核对账户、持仓、券商接口状态
```

盘前候选不是自动买入信号；生成时间不在 9:20–9:40 时会显示“非窗口生成/历史候选”。

### 7.2 盘中

情绪锚看板：

```text
情绪阶段
涨停/跌停
主线
锚点
量能
外围
```

T+0：

```text
情绪信号 → ETF 目标
手动确认下单
自动执行需显式启动
14:55 清仓约束
```

T+1：

```text
情绪锚浮现 → 人工加入股票池
逐股指定策略
自动执行需 live
T+1 当日不可卖
```

### 7.3 收盘

```text
查看执行记录
核对账本
写交易计划复盘
生成盘前候选
备份
```

## 8. 主动交易

```text
交易台 → 主动交易
```

流程：

```text
填代码 → 取行情
填限价/数量/止损/目标
写交易理由
三项人工确认
风控预检
提交真实委托
```

风控预检不会发单；提交仍走统一券商通道。

如果预检失败：

```text
看 checks 里的具体规则
到 风控 → 风控编排 调整规则/参数
不要为了下单直接关闭硬规则
```

## 9. T+0 交易

```text
交易台 → T+0 交易
```

流程：

```text
看情绪信号/目标 ETF
核对接口状态和账户
进入实战下单（仅 live）
手动确认
查看执行审计/今日记录
```

自动执行：

```text
开始自动
暂停
全部清仓
```

约束：

- 自动执行需要 live 且账户可用。
- 默认暂停；重启不会自动恢复，除非显式配置。
- 所有卖出走统一券商通道。

## 10. T+1 量化

```text
交易台 → 量化交易
```

步骤：

```text
1. 从情绪锚浮现选择股票，人工加入池
2. 可逐股指定策略
3. 在量化策略库创建/编辑策略
4. 运行日线回测
5. 参数稳健性
6. 启用策略
7. 启动 T+1 自动（仅 live）
```

策略启用有质量门槛；不满足时会要求显式确认。

回测包含：

```text
费用
滑点
涨跌停
停牌/零成交
T+1
样本外
滚动窗口
夏普/索提诺/盈亏比
```

回测不是未来收益保证。

## 11. 风控

```text
交易台 → 风控
```

包含：

```text
风控编排
止损监控
策略额度
紧急停止
交易账本
风控事件
```

### 风控编排

```text
22 条买入前置规则
启用/停用
拦截/告警
参数
作用范围：主动交易/T+0/T+1
```

硬规则不能关闭，也不能降为告警：

```text
交易时段
行情可用
价格有效
整手
可用资金
账户总仓位
当日亏损
行情新鲜度
重复委托
```

保存失败会显示具体违规规则。

### AI 风控草稿

```text
风控编排 → AI 生成编排
```

AI 生成后必须人工检查、保存、启用；违反硬规则会被服务端拒绝。

### 止损

止损监控独立于买入风控：

```text
固定止损 / 移动止损
扫描间隔
自动卖出或只告警
```

自动卖出需要可用持仓和 live 接口。

## 12. 分时

```text
主动交易 → 分时检查
```

输入代码：

```text
1 分钟价格
VWAP 均价线
红绿量柱
3× 中位量
B1/B3/B4/S1/S2 标记
红旗
```

数据闸门：

```text
收盘日至少 200 根
盘中至少 2 根
时间递增
累计成交量不回退
VWAP 越界拒绝
板块涨跌停校验
```

分时分析不会自动下单。

## 13. 回测

T+1：

```text
量化策略库 → 回测代码/交易日 → 运行回测
```

T+0：

```text
T+0 策略库 → 5 日分时验证
```

公司行为：

```text
分红/送转/除权
日线回测前复权
```

回测结果会显示复权次数和数据质量。

## 15. 常见问题

### 券商 fetch failed

```text
适配器未启动
地址/端口错误
Windows 客户端未登录
防火墙阻止
```

处理：

```text
启动适配器
系统设置 → 测试接口
确认 mode/health
```

### 页面显示休市/上一交易日

行情是最近一次交易日快照；周末/盘前显示上一交易日属于正常。

### 盘前候选是空的

```text
未到生成窗口
服务当天未收到有效快照
候选过滤后为空
```

可手动点“生成”，但非窗口生成会显示“非窗口”。

### 自动执行按钮不可用

```text
接口不是 live
账户未读取
股票池为空
存在未完成委托
```

### AI 不可用

```text
未配置 Key
Base URL/模型错误
网络超时
```

本地推理仍可用。

### 风控保存失败

看提示：

```text
硬风控不能关闭/降为告警
参数超出范围
```
