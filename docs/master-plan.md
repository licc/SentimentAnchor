# 情绪锚系统 · 生产化改造主计划

## 目标

把当前单操作者实盘研究系统，逐步改造成：

```text
可持续运行
可对账
可熔断
可回测
可审计
可回滚
```

不追求一次性微服务化，按风险优先级推进。

---

# 阶段一：交易安全（P0）

## 1. 持久化订单意图 + 幂等键（已完成）

验收：

```text
任何下单前先写入 order-intent
同一 clientOrderId 不能重复发送
进程崩溃后能列出未完成意图
启动时能对账，不重复下单
```

实现：

```text
server/services/order-intent.ts
data/order-intents.json
```

## 2. 启动强制对账

验收：

```text
服务启动后先核对未完成 intent / execution
存在未知委托时自动执行状态为 paused/recovering
不自动开新仓
```

## 3. 自动执行重启安全（已完成）

已完成：

```text
默认重启暂停
AUTO_RESUME_ON_RESTART=true 才恢复
```

## 4. 数据异常熔断

已完成部分：

```text

```


验收：

```text
策略额度
单标的互斥
同一时刻只有一个开仓动作
```


启用端和服务端都增加参数稳健性门槛：正收益邻域低于 40% 时拒绝，人工强制启用需 `force=true`。

已增加参数邻域稳健性测试（止损/止盈各 ±0.5/1），用于识别过拟合。

# 执行规则

1. 每个阶段先补测试，再改行为。
2. 实盘写操作必须有幂等键。
3. 自动执行默认暂停，人工恢复。
4. 所有写操作走统一券商通道。
5. 每阶段完成构建、冒烟和回滚点。
