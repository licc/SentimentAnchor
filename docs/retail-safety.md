# 散户实盘安全包

## 自动备份

- 数据目录：`data/*.json`、`data/*.db`
- 备份目录：`data/backups/backup-*`
- 默认每 24 小时一次，保留 14 份
- 页面：系统设置 → 自动备份
- 接口：`GET/POST /api/system/backup`、`POST /api/system/backup/config`

## 手机告警

- 通道：Server酱 / PushPlus / Webhook
- 页面：系统设置 → 手机告警
- 触发：告警事件、系统风控告警
- 测试：`POST /api/system/notify/test`

## 常用策略

已加入 T+1 策略库：

- 龙头跟随
- 趋势确认
- 回踩承接
- 20 日突破
- 回踩低吸

T+0 策略库保留：

- 情绪轮动
- 防守优先
- 只做防守

## 止损策略

- 固定止损
- 移动止损（从持仓最高浮盈回撤触发）
- 风控策略库新增“移动止损 2%”

## 交易计划与复盘

- 主动交易提交后生成计划
- 计划包含：代码、方向、价格、数量、止损、目标、风险金额、理由
- 交易后写复盘，记录是否按计划执行
- 数据：`data/trade-plans.json`
- 页面：主动交易 → 交易计划 / 复盘

## 风险定仓

主动交易支持：

```text
账户风险比例
止损价
按风险计算数量
```

公式：

```text
数量 = floor(账户资产 × 风险% ÷ (买入价 - 止损价) ÷ 100) × 100
```

## ST / 停牌

- 买入风控新增目标行情可用检查
- 名称含 ST / 退 的标默认拦截
- 行情缺失/疑似停牌禁止买入
- 公告暂无独立数据源，使用黑名单人工过滤
