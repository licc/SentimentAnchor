## 二、真正有价值且应保留

1. **统一券商通道 + 订单意图 + 账本**：这是实盘系统的基础，不是展示。
2. **风控编排**：22 条规则可组合，硬规则全通过才委托。
3. **T+0/T+1 独立策略范围**：共享账户但分开规则和额度。
4. **日线回测 + 稳健性门槛**：至少能淘汰明显过拟合策略。
5. **1 分钟 VWAP/量价/红旗**：买点风控有真实数据依据。
6. **账本/执行审计/对账**：能回答“这笔到底有没有成交”。
7. **备份/告警/交易计划**：散户生存能力，不是花活。
