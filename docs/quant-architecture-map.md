# 量化系统模块对照

参考链路：

```text
数据 → 策略 → 回测/模拟 → 执行 → 风控 → 分析
```

## 当前实现

| 模块 | 当前能力 | 状态 |
|---|---|---|
| 数据接入 | 新浪实时行情、东方财富/同花顺历史、情绪快照、60s 全球恐慌缓存 | 可用 |
| 数据存储 | 日线按需读取；交易账本 SQLite；策略/配置 JSON | 可用，非时序库 |
| 数据服务 | 统一 Snapshot、SSE、缓存、历史 K 线接口；新增腾讯 1 分钟分时 | 可用 |
| 策略开发 | T+0 文字策略、T+1 文字策略、规则模型、AI 生成参数 | 可用 |
| 策略管理 | 策略库、版本、启停、单模块启用、逐股策略指定 | 可用，单活动策略 |
| 信号 | 情绪阶段/分数/趋势 → 目标 ETF / T+1 股票 | 可用 |
| 分时分析 | 1 分钟 VWAP、量比、峰值量、收盘位置、趋势效率、红旗、B1-B4/S1-S4；规则库标注保留/观察/不建议 | 新增 |
| 回测撮合 | 日线、次日开盘、手续费、滑点、整手、T+1、涨跌停、停牌 | 可用 |
| 回测评估 | 收益、回撤、胜率、样本外、滚动窗口、夏普、索提诺、盈亏比、基准 | 可用 |
| 回测防过拟合 | 参数邻域稳健性、40% 启用门槛 | 可用 |
| 订单管理 | 订单意图、clientOrderId 幂等、状态、成交、撤单、账本 | 可用 |
| 执行网关 | 单一 thsapi 网关、统一 brokerChannel / brokerCommand 串行队列 | 可用 |
| 智能路由 | 未实现多券商/多目的地路由 | 未实现 |
| 事前风控 | 时段、资金、单笔、单票、总仓、黑名单、重复、日亏损、策略额度 | 可用 |
| 事中风控 | 止损扫描、急停、暂停、持仓价格校正 | 可用 |
| 事后风控 | 风控事件、拦截统计、组合盈亏/胜率/盈亏比 | 部分 |
| 组合管理 | 共享账户、持仓、可用数量、FIFO 已实现盈亏、策略额度 | 可用 |
| 资金分配 | T+0/T+1 独立额度、账户总额度、优先级 | 可用 |
| 绩效分析 | 回测绩效、组合已实现盈亏、手续费、按标的归因 | 可用 |
| 归因分析 | 标的级已实现盈亏；无行业/因子归因 | 部分 |
| 监控 | 系统健康、指标、告警、账本一致性、订单意图 | 可用 |
| 告警通知 | 告警事件 + Webhook | 可用 |
| 日志审计 | 执行审计、订单意图、账本、风控事件 | 可用 |
| 事件引擎 | 进程内事件/队列 + SSE | 可用，非分布式 |
| 交易时钟 | 交易日历、交易时段、截止时间 | 可用 |
| API 网关 | REST + SSE | 可用 |
| 部署 | 单进程 + JSON/SQLite；Windows 券商外部进程 | 单机 |

## 距离机构级还缺

```text
多策略并行组合回测
组合优化器 / 风险平价 / 资金分配模型
行业/因子归因
多券商智能路由
Tick / Level-2 / 时序数据库
分布式事件总线
多用户/RBAC（当前明确不做）
```

## 当前定位

```text
单操作者、单券商、小资金实盘量化工作台
核心链路完整
不是机构级多策略平台
```
